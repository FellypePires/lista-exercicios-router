# Lista de exercícios de rotas

Projeto Angular feito no mesmo formato do exemplo, com componentes standalone e arquivos separados para TypeScript, HTML e CSS.

Para executar, instale as dependências com `npm install` e inicie com `npm start`.

As rotas usam os caminhos da lista sempre que possível. Como duas atividades definem `/` e `/dashboard`, a página inicial do exercício 7 fica em `/cursos-inicio` e o painel do exercício 6 fica em `/admin/dashboard`. A página `/lista` reúne links para as atividades.
